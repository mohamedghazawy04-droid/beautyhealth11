# 🌿 عناية أكتوبر وزايد | CareHub October & Zayed

متجر إلكتروني متكامل لمنتجات العناية بالبشرة، الجسم، الشعر، ومستلزمات الأطفال مع نظام توصيل سريع وفوري مخصص لأحياء ومدن **٦ أكتوبر والشيخ زايد**.

---

## ✨ المميزات الرئيسية للمتجر

- 🛒 **كتالوج منتجات شامل**: تصفح وتصنيف المنتجات حسب الفئات (عناية بالبشرة، الجسم، الشعر، الأم والطفل).
- 📍 **محدد النطاقات والأحياء**: دعم جميع أحياء ومناطق أكتوبر والشيخ زايد مع حساب فترات التوصيل ورسوم الشحن المخصصة.
- 💬 **مستشارة العناية الذكية (AI Consultant)**: اقتراح روتين مخصص للمستخدم ونوع بشرته أو مشاكل الشعر.
- 📦 **تتبع الشحنات والطلبات**: متابعة حالة الطلب لحظياً (قيد التجهيز، مع المندوب، تم التسليم) مع بيانات المندوب.
- ⭐ **نظام تقييم المنتجات بالنجوم**: إمكانية تقييم المنتجات بعد الاستلام بالنجوم والتعليق وحساب متوسط التقييمات تلقائياً.
- 💳 **خيارات دفع محلية**: الدفع عند الاستلام مع المعاينة، فودافون كاش، وإنستاباي (InstaPay).
- ⚙️ **لوحة إدارة متكاملة (Admin Portal)**: متابعة الطلبات، تحديث الحالات، إدارة المخزون وإضافة منتجات جديدة.

---

## 🚀 التشغيل والتثبيت محلياً (Local Setup)

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. تشغيل السيرفر في وضع التطوير (Dev Mode):
```bash
npm run dev
```
سيعمل التطبيق على الرابط المحلي: `http://localhost:3000`

### 3. بناء المشروع للإنتاج (Production Build):
```bash
npm run build
npm start
```

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend**: React 19, TypeScript, Tailwind CSS, Motion, Lucide Icons
- **Backend & Bundling**: Express, Vite, ESBuild, TSX
- **AI Integration**: Google GenAI SDK
